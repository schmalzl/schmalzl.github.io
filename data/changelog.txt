SUBSONIC CHANGELOG
==================

VERSION 0.1.2
DATE: 2026-11-18

[ADDED]
- Logout button in the navigation.

[CHANGED]
- Darker blue and a deeper, greener green.
- Meter visualizer uses yellow for its middle range again.
- Buttons, inputs and track rows are slimmer; the analyzer is shorter.
- Compact layout is now the default (use Reset settings to apply it to existing settings).
- Less spacing between items in Settings.
- Removed the volume sliders (use the device volume).

[FIXED]
- iPhone: the login screen no longer zooms in when selecting a field.
- Confirmations use an in-page dialog instead of the browser dialog, which interrupted audio and left the song running silently.
- The audio engine resumes automatically if the system suspends it during playback.

VERSION 0.1.1
DATE: 2026-11-18

[CHANGED]
- Removed the CRT scanline effect and its setting.
- New black, blue and green color scheme; the logo is now green and blue.
- Track list items are smaller and more compact.

[FIXED]
- iPhone: audio session set to playback so sound can continue with the screen locked or the browser in the background, and the audio engine resumes when returning to the page.

VERSION 0.1.0
DATE: 2026-11-18

[ADDED]
- Login screen with client-side access gate (PBKDF2 salted hashes), masked user list and news.
- Diagnostic-style loading screen driven by real initialization steps.
- Music library from data/music.json, grouped by artist, with search.
- Playback: play/pause, prev/next, seek, volume, repeat one/all/none, Media Session.
- Visualizer: meter, spectrum, waveform, spectrogram, oscilloscope.
- Settings (persisted locally), About, local Stats.
- admin/manage_users.py and admin/generate_manifest.py.

[FIXED]
- Initial release.
